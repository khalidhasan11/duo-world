# 🧩 Duo World: Puzzle Voyage

Two travellers. One puzzle. Finish every level **together**.

An original 3D co-op puzzle game in the style of Pepelo 2 — built as a web
game (Three.js) with a shared engine that will also power the online co-op
server and a signed Android APK.

**▶ Play it live: https://khalidhasan11.github.io/duo-world/**

## This build — Phase 1 (offline solo)
- **10 levels**: World 1 Dhaka (1–5) and World 2 Quebec (6–10, ice physics)
- Solo play the co-op way: you control **one traveller at a time** and
  SWITCH between them — one holds a switch, the other crosses
- Pushable crates (their weight holds switches), latch doors, exit pads
- Stars, best times and level unlocks saved on your device

**Controls:** WASD / arrows · Space jump · **Tab / Q = switch traveller**
Touch screens get a D-pad, JUMP and SWITCH buttons automatically.

## Roadmap
Phase 0 (network prototype) and Phase 1 (this build) are done. Next is
Phase 2: real online co-op — rooms with codes, one traveller per phone,
reconnect handling — running on this same engine, then the remaining
40 levels, skins, and the Android release.
